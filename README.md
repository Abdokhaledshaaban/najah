# ENQEZ Ultimate — Frontend Presentation Project

## التقنية
HTML5 + CSS3 + JavaScript + Bootstrap 5 + Bootstrap Icons.
لا يوجد React / JSX / Backend / Database.

## الصفحات
- index.html — Landing + المشكلة + الفكرة + المميزات
- problem.html — تحليل المشكلة ومسار الحل
- cases.html — مكتبة الحالات الست
- guide.html — Emergency Mode + Decision Guide + Scenario Simulator
- learn.html — Micro Learning + Checklist
- about.html — المشروع + QR + المصادر

## الحالات
Stroke / Choking / Cardiac Arrest / Severe Bleeding / Burns / Drowning.

## QR Code
افتح `js/app.js` وعدّل:
const SITE_URL="https://example.com";
إلى رابط موقعك النهائي.

## التشغيل
افتح `index.html` أو استخدم Live Server في VS Code.

## ملاحظة طبية
هذا Prototype تعليمي. الإرشادات الطبية تتغير، ويجب مراجعة المحتوى مع مختصين ومصادر محلية قبل أي استخدام واقعي.
المراجع الأساسية:
- 2025 American Heart Association Guidelines for CPR and ECC
- 2024 American Heart Association + American Red Cross Guidelines for First Aid
